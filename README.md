## 📚 项目简介

本项目是一个**芯片数字后端（Physical Design）面试题库刷题网页**，涵盖 **160+ 道** 后端面试高频题，包括但不限于：

- Floorplan / Placement / CTS / Routing
- STA（静态时序分析）
- 低功耗设计（Power Gating、Multi-Vt、Clock Gating）
- 物理验证（DRC / LVS / ERC）
- IR Drop / EM / Cross-talk
- UPF / 多电压域
- 工具流程（Innovus / ICC2）

每道题均包含：
- ✅ 标准答案
- ✅ 技术解析（原理 + 实际项目经验）

适合**数字后端面试准备**、**校招/社招突击**、**日常知识温习**。

---

## ✨ 功能特点

- 🎯 **160+ 道高频题**，覆盖数字后端全流程
- 📖 **答案 + 解析**，不止背诵，更懂原理
- 🧭 **上一题 / 下一题 / 随机跳转**，自由刷题
- 📱 **响应式设计**，手机 / 电脑 / 平板全适配
- 🔍 **搜索功能**（可选），快速定位知识点
- 💾 **本地进度保存**（localStorage），下次继续
